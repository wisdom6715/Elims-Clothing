# Elims Storefront Design Notes

The storefront has been translated into a responsive editorial system centered on deep forest green, sage, cream, warm almond, and terracotta. The visual language pairs a serif display face with restrained sans-serif utility text, rounded editorial panels, thin botanical-gray separators, and compact uppercase labels.

The home page replaces the earlier category drill-down framing with a direct in-page collection ribbon for **Women**, **Men**, **Children**, and **Accessories**. Firebase remains the source of truth for the live product rail, product data, authentication, carts, addresses, reviews, and order-related flows. The legacy admin console and legal-page routes are intentionally outside these presentation changes.

The hero uses CSS-driven tonal layering rather than a copied reference image, so the page remains visually cohesive without adding unavailable runtime media. Product imagery remains sourced from the client’s existing Firebase catalogue.
